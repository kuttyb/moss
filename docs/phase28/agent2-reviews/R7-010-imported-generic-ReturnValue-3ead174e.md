No new consumer type inference was found.

Duplicate owners or an empty semantic callable identity also fail closed. Native generation still consumes exact ReturnValue checker facts. Return actions remain the existing primitive read-copy versus nonprimitive consume/transfer decision; this patch adds no copy policy, clone, or exception.
